## 2024-08-01 - Todo List Accessibility & Hit Area
**Learning:** Found a common anti-pattern where checkboxes in lists were not wrapped in `<label>` tags alongside their corresponding text. This forced users to click the tiny checkbox itself to toggle state, leading to poor usability. Additionally, dynamic inline style bindings (`:style`) in Vue fail silently if the CSS property is misspelled (e.g., `text-decoration:line-trought`), resulting in broken visual feedback.
**Action:** Always verify that interactive form elements like checkboxes or radio buttons are wrapped in `<label>` tags with their text to maximize the clickable hit area. When using dynamic inline styles for state indication, explicitly verify CSS spellings against expected visual output to catch silent failures.
