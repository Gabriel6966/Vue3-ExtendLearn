## 2024-05-16 - Todo List Accessibility & Visual Fix
**Learning:** Native input and select fields missing labels hinder screen reader accessibility, and wrapping checkboxes in labels significantly improves usability by increasing the hit area. CSS typo in text-decoration prevents visual feedback on task completion.
**Action:** Add aria-labels to all form inputs without explicit labels, always wrap checkbox inputs with their descriptive text inside a label tag, and verify CSS spelling for dynamic style bindings.
