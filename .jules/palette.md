## 2025-01-20 - Todo List Accessibility Enhancements
**Learning:** Native HTML form inputs without visible text labels require explicit `aria-label` attributes to be accessible. Furthermore, wrapping checkboxes and their corresponding descriptive text inside a `<label>` tag significantly increases the clickable hit area, improving usability.
**Action:** Always add `aria-label` to inputs missing explicit visual labels and always wrap checkboxes with their associated text in a `<label>` tag.
