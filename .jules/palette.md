## 2023-10-25 - Todo List Empty State
**Learning:** The Todo List component lacks an empty state, making it confusing when there are no tasks or when a filter returns no results. This is a common pattern where lists start empty or get emptied via filtering, and users need clear feedback that the system is working but there's just no data. Since this app forces text color to `#2c3e50` globally, any new plain text added needs to use heading tags like `<h3>` to inherit the correct `#ffffff` heading color on dark mode backgrounds.
**Action:** Add empty states to lists when they can be empty. Use heading tags (e.g., `<h3>`) for empty state text to ensure proper text color inheritance and contrast, and ensure the message is contextual (e.g., "No tasks" or "No tasks found for this filter").
